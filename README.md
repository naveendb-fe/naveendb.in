# Naveen DB — Personal site

Vite + React portfolio for [naveendb.in](https://naveendb.in).

## Stack

- React 19 + TypeScript
- Vite
- React Router
- Tailwind CSS
- Framer Motion
- react-helmet-async

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Produces a static `dist/` with prerendered `/` and `/work/*` HTML shells for crawlers and static hosting.

## Deploy

Connect this repo to Vercel (or Cloudflare Pages). `vercel.json` includes SPA rewrites.
